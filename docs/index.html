socks5-bench

Benchmark latency, reliability, and IP rotation of SOCKS5 proxies from the command line. Works with any provider.

What it measures

⚡

Health Check

Verify proxies are alive. Get the exit IP, country, and response time in one request.

⏱

Latency Benchmark

Measure avg, p50, and p95 latency over N requests with configurable concurrency.

🌐

IP Rotation

Count unique exit IPs across requests. Verify your rotating proxy actually rotates.

📊

JSON Export

Export structured results to JSON for integration with monitoring, dashboards, or CI pipelines.

Metrics explained

MetricDescription
latency (avg/p50/p95)Round-trip time through the proxy. P50 is the median. P95 captures tail latency spikes.
success ratePercentage of requests that returned HTTP 200 through the proxy.
unique IPsDistinct exit IPs observed. Static proxies show 1. Rotating proxies should show many.
rotation ratioUnique IPs / total requests. 100% means every request used a different IP.
